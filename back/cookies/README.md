# Cookies для yt-dlp

Сюда можно положить Netscape cookie-файлы платформ: `youtube.txt`, `rutube.txt`,
`vk.txt`, `twitter.txt`, `tiktok.txt`, `instagram.txt`.

Файла нет — соответствующая платформа запускается без cookies. Для обычных
публичных роликов cookies не требуются. Они нужны только когда платформа сама
запрашивает авторизацию, возраст или доступ аккаунта.

TikTok для публичных ссылок в первую очередь требует браузерную имитацию через
`curl-cffi`; cookies не заменяют эту зависимость.

# a4loader для Android

Перед сборкой установите зависимости командой `npm install`. Для разработки нужен Android dev build: модуль фоновой службы не работает в Expo Go. Запустите `npm run android` для установки dev build на подключённое устройство; затем используйте `npm start`.

Проверки: `npm run typecheck`, `npm run lint`, `npm test`. Для повторяемой установки из lock-файла используйте `npm ci`.

После успешного сохранения то же уведомление меняет статус на «Загрузка завершена», лишается шкалы и становится смахиваемым. Оно отвязывается от службы через Android `STOP_FOREGROUND_DETACH`, поэтому завершение службы его не удаляет. При отмене или ошибке уведомление об успехе не показывается. Изменение применяется нативным плагином при следующей сборке: один JS Reload не добавит новый native-метод в ранее установленный APK.

Release APK собирается командой `npm run build:android`. После успешной сборки скрипт копирует APK в `build/a4loader.apk`. Он использует JDK 17 и Android SDK, найденные в стандартных местах Windows, и собирает только `arm64-v8a`. Такой APK не установится на устройства только с 32-битным ARM. APK содержит сжатые native-библиотеки; после установки Android распакует их, поэтому занимаемое приложением место будет больше размера APK.

API задаётся в `src/services/api.ts`. Для загрузки в фоне Android показывает обязательное постоянное уведомление. Свертывание приложения и блокировка экрана не останавливают загрузку. Смахивание приложения из списка недавних отправляет событие `a4loaderTaskRemoved`: клиент отменяет текущую загрузку и сообщает серверу об отмене, после чего служба останавливается. Если JavaScript не успевает завершить отмену, служба принудительно завершится через 10 секунд. После явного закрытия автоматического возобновления нет.

Для одного экрана с `Slot` не нужны нативные модули Drawer, Reanimated и Worklets: они исключены из Android autolinking в `package.json`. Если позже добавите выдвижную навигацию или Reanimated-анимации, уберите соответствующие исключения перед пересборкой.

Плагин `withShortCmakePaths` ограничивает длину путей объектных файлов CMake: это обходит лимит старого Ninja на Windows без переноса репозитория и изменения системных настроек.

При первой загрузке Android 13 и новее приложение попросит разрешение на уведомления. На Android ниже 10 при первой загрузке потребуется разрешение на сохранение в общую папку Downloads. Загруженный файл сохраняется в `Downloads/a4loader`.

Иконка Android использует белый фон днём и тёмно-серый в ночном режиме. Для ночного режима также задан ресурс `splashscreen_background`. Некоторые лаунчеры кэшируют значки, поэтому после смены темы новая подложка может появиться не сразу. SVG-иконки подключаются как компоненты через `react-native-svg` и Metro transformer.

SVG импортируется обычным компонентом: `import YouTubeIcon from './assets/icons/platform-youtube.svg'`, затем `<YouTubeIcon width={18} height={18} color={colors.textAccent} />`. Растровая тонировка для SVG больше не используется. У YouTube и Rutube CSS-цвет внутреннего символа заменён прозрачным вырезом: CSS-переменные внутри SVG в Android недоступны.

Превью в вебке и приложении использует одинаковую последовательность: новый URL создаёт компонент с `key`, до события `onLoad` показан только прямоугольный скелетон, после загрузки отображается картинка с её реальными пропорциями. При `onError` превью скрывается, остальные данные остаются. Высота и максимальная ширина совпадают с веб-брейкпоинтами: 65/116, 100/190 и 110/220. Шкала приложения показывает серверную подготовку до 100% и не сбрасывается во время передачи файла на телефон; отдельный прогресс передачи используется только уведомлением.

Это локальная тестовая release-сборка со стандартной debug-подписью Expo. Для публикации понадобится собственный постоянный ключ подписи. Исходный логотип сохранён в `assets/images/logo.svg`, Android использует подготовленные из него PNG-ресурсы.

На некоторых прошивках энергосбережение может принудительно остановить даже фоновую службу. При принудительной остановке приложения Android не гарантирует вызов отмены: сервер очистит оставшуюся задачу по таймауту активности. Приложение само её не возобновляет.
